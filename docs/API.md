# Command API

Generated from the command registry by `npm run docs:api`. Do not edit this file by hand.
The headset UI, the in-app assistant, and external agents all call these commands.

A call returns `{ status: "ok", result }` or `{ status: "error", error }`.
Destructive commands called by an assistant or an external agent return `{ status: "confirmation_required", command, params, description }` until the call is repeated with confirmation.
Clicks in the headset pass as the user, so they count as confirmation.

Command count: 62.
